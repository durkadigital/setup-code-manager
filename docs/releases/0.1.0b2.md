# Setup Code Manager 0.1.0b2

Diese Beta verbessert das Erfassen von QR-Codes auf dem Smartphone.

- Safari lädt Fotos zuerst über das native Bildelement. Der zuvor bevorzugte
  Bitmap-Pfad konnte ein lesbares Gerätefoto für die QR-Erkennung unbrauchbar machen.
- Fotos werden in mehreren begrenzten Größenstufen geprüft. So lassen sich auch
  kleine Gerätecodes erkennen, die bei der bisherigen einzelnen Größe übersehen wurden.
- Ohne verfügbare Livekamera erscheint **Foto aufnehmen**. Der benutzergesteuerte
  Dateidialog fordert die rückseitige Kamera an; **Foto auswählen** bleibt separat verfügbar.
- Während der Fotoerkennung wird der Fortschritt angezeigt. Fotos und QR-Inhalte
  werden lokal verarbeitet; die Fotos werden weder hochgeladen noch gespeichert.
- Der mobile Dialog berücksichtigt den oberen Sicherheitsabstand der Companion-App.
- Bildformat- und Ladefehler werden von einem nicht erkannten QR-Code unterschieden.

## Aktualisierung

Im Marketplace beim benutzerdefinierten Repository
`durkadigital/setup-code-manager` **Vorabversionen einschließen**, die Informationen
aktualisieren und **0.1.0b2** installieren. Home Assistant anschließend neu starten
und das Panel neu laden. Bereits gespeicherte Einträge bleiben erhalten; das
Speicherformat wurde nicht geändert.

## Grenzen

Geprüft mit 270 Python- und 33 JavaScript-Tests sowie einem echten Gerätefoto im
vollständigen lokalen Safari-Panel. Der erkannte Code wurde dabei nicht gespeichert.

Die fortlaufende Livekamera im Browser benötigt weiterhin HTTPS. Die konkrete
Fotoaufnahme-Oberfläche hängt vom Browser und der Companion-App ab und muss auf
dem jeweiligen Smartphone geprüft werden. Es wird keine native HA-Scanner-Schnittstelle
überschrieben und keine Netzwerkkonfiguration geändert.

Ein erfolgreicher Fototest ersetzt weder die Prüfung aller Geräteaufkleber noch
den noch offenen vollständigen HA-Backup-/Restore-Test.
