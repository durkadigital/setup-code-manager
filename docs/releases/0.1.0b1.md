# Setup Code Manager 0.1.0b1

Erste Vorabversion zum Testen in Home Assistant. Vor der Installation eine aktuelle
HA-Sicherung anlegen. Die ursprüngliche Integration **Setup Codes** und ihre Daten
bleiben erhalten; diese Version verwendet die eigene Domain `setup_code_manager`.

Im Marketplace von HA 2026.11 das Repository
`https://github.com/durkadigital/setup-code-manager` als Integration hinzufügen.
**Vorabversionen einschließen vor der Installation aktivieren** und ausdrücklich
**Setup Code Manager 0.1.0b1** auswählen. Der Standardbranch `main` enthält derzeit
noch den früheren Stand. Nach einem gegebenenfalls angeforderten Neustart die neue
Integration über **Geräte & Dienste** hinzufügen.

- Lokale QR-Erkennung per Kamera oder Foto für Matter, HomeKit und Z-Wave.
- HA-Geräteauswahl nach fehlendem Protokollcode; andere gespeicherte Codes bleiben erhalten.
- Eigenständiges Inventar mit Archiv: Entfernen eines HA-Geräts löscht keinen Code.
- JSON-/CSV-Export, Importvorschau und ausdrückliche Konfliktentscheidung.
- Vorschau zur Übernahme der ursprünglichen Setup-Codes-Daten, ohne die Quelle zu ändern.
- Oberfläche auf Deutsch/Englisch; Zugriff nur für HA-Administratoren.

Lokal automatisiert geprüft, einschließlich eines isolierten Starts mit echtem
HA Core 2026.11.0, HTTP/WebSocket-Zugriff und Datenerhalt beim Neuladen. **Noch keine
Abnahme mit echten Geräten, Smartphonekamera/Companion-App oder vollständigem
HA-Backup-Restore.** Vorgesehen ab HA 2026.1; ältere HA-Stände sind noch nicht
praktisch geprüft. Diese Vorabversion ist keine stabile Freigabe oder Katalogaufnahme.

Bekannte Grenzen: ein Code je Protokoll und Gerät; keine Gerätekopplung oder OCR;
zusammengesetzte Matter-QRs und nicht unterstützte optionale TLV-Typen werden
abgelehnt. CSV benötigt das feste Exportformat. Exporte enthalten lesbare Codes.
Livekamera benötigt einen sicheren Browserkontext und Kamerafreigabe.

[Installation](https://github.com/durkadigital/setup-code-manager/blob/0.1.0b1/README.md#testinstallation)
und [Abnahmeplan](https://github.com/durkadigital/setup-code-manager/blob/0.1.0b1/docs/TESTING.de.md).
Fehler bitte mit Version und Reproduktionsschritten melden, ohne echte Codes,
Zugangsdaten oder private Exporte anzuhängen.
