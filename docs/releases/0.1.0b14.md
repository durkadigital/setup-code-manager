# Setup Code Manager 0.1.0b14

- **Erneut verknüpfen** verbindet einen gespeicherten Eintrag mit dem neu gekoppelten Home-Assistant-Gerät. Einrichtungscodes und Notizen bleiben erhalten. Ein Zweiteintrag ohne eigene Daten wird beim Bestätigen zusammengeführt.
- Die Auswahl zeigt verfügbare Seriennummern an. Ein eindeutiger Treffer bei Hersteller, Modell und Seriennummer wird als Vorschlag markiert. Wenn die alte Seriennummer fehlt, kannst du das Gerät manuell auswählen.
- Home Assistant liefert den aktuellen Namen und Raum. Zweiteinträge mit eigenen Codes, Notizen oder anderen gespeicherten Angaben bleiben geschützt.

Für das Update im Marketplace Vorabversionen einschließen, **0.1.0b14** auswählen und Home Assistant anschließend neu starten.
