# Setup Code Manager 0.2.0b1

- **Code fehlt** öffnet die passende Codekarte des Geräts. Auf dem Handy sind die Zeilen kompakter und gespeicherte Ansichten direkt erreichbar. Nach dem Schließen eines Dialogs kehrt der Tastaturfokus zum Auslöser zurück.
- Ist auf einem Foto kein lesbarer Matter-QR vorhanden, kann der Manager gedruckte 11- oder 21-stellige Matter-Codes lokal erkennen. Vergleiche den Vorschlag mit dem Aufdruck und bestätige ihn vor dem Speichern.
- Die Übersicht lädt den Codestatus. Anzeigen oder Kopieren ruft den einzelnen Code ab. Home Assistant durchsucht die Codes bei Bedarf. Beim Wechsel in den Hintergrund werden angezeigte Codes wieder verdeckt.
- Unter **Exportieren** lässt sich das Inventar oder eine Auswahl als passphrasengeschützte `.scmb`-Datei sichern. Die Importvorschau zeigt Änderungen bis zum einzelnen Code. JSON, CSV und PDF stehen weiterhin zur Verfügung.
- Die Startprüfung und der Import aus dem privaten Speicher von *Setup Codes* entfallen. Bereits übernommene Einträge bleiben im Inventar.

Für Home Assistant ab 2026.11.0. In den Repository-Details die Vorabversion **0.2.0b1** wählen, installieren und Home Assistant neu starten. [Installation](https://github.com/durkadigital/setup-code-manager/blob/0.2.0b1/docs/INSTALLATION.de.md)
