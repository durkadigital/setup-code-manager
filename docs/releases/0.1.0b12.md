# Setup Code Manager 0.1.0b12

- **Code hinzufügen** öffnet direkt die passende Codekarte. Die Tastatur erscheint beim Antippen eines Eingabefelds. Das gilt auch für die geführte Erfassung fehlender Codes.
- Die Geräteübersicht zeigt **Code gespeichert** mit grünem Haken und **Code fehlt** mit gelbem Warnsymbol. Mobil steht der Status rechts, am Desktop in der Spalte **Codes**. Die Erreichbarkeit gehört weiterhin zur Home-Assistant-Verknüpfung.

Die Desktop-Ansicht und die mobile Ansicht bei 390 und 320 Pixeln wurden in Safari am Mac mit Beispieldaten geprüft. Bei einem verknüpften Gerät landete der Fokus auf der Codekarte. Nach dem Speichern wechselte die Anzeige in der Liste zu **Code gespeichert**. Der Test in der iPhone-App steht noch aus.

Für das Update im Marketplace Vorabversionen einschließen, **0.1.0b12** auswählen und Home Assistant anschließend neu starten. [Installation](../INSTALLATION.de.md)
