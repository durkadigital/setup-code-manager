# Setup Code Manager 0.1.0b7

Diese Vorabversion erweitert die Suche und die Filter in der Geräteübersicht.

## Änderungen

- Suche nach Notizen, Codebeschreibungen, gespeicherten QR-Inhalten und manuellen
  Codes, einschließlich des aus einem Matter-QR berechneten Zifferncodes.
- Numerische Codes mit oder ohne Leerzeichen und Bindestriche finden; führende
  Nullen bleiben erhalten. Die Zeichen eines `MT:`-Inhalts werden wörtlich gesucht.
- Raumfilter mit **Alle Räume**, **Ohne Raum** und den vorhandenen Räumen.
  Verknüpfte Geräte verwenden ihre aktuellen HA-Räume; entfernte Geräte behalten
  den zuletzt bekannten Raum. Mehrfachverknüpfungen berücksichtigen jeden Raum.
- Die Checkbox **Code fehlt** wird durch **Alle Codes / Code vorhanden / Code fehlt**
  ersetzt. Bei ausgewähltem Protokoll bezieht sich der Codestatus auf dieses Protokoll.
  Beispielsweise zeigt **Kinderzimmer + Matter + Code fehlt** auch Geräte mit einem
  HomeKit-Code an, solange ihnen der Matter-Code fehlt.
- Alle Filter lassen sich mit der Suche und den Ansichten **Alle**, **Verknüpft**,
  **Nicht verknüpft** und **Archiv** kombinieren. Trefferzahl und **Filter zurücksetzen**
  erscheinen bei aktiven Filtern; Zurücksetzen erhält die ausgewählte Ansicht.
- Auf schmalen Bildschirmen stehen Raum und die beiden weiteren Filter in zwei
  Zeilen. Fokus und Scrollpositionen bleiben beim Aktualisieren bedienbar.

## Prüfen und aktualisieren

299 Python-Tests, 104 JavaScript-Tests und Ruff bestanden. Die lokale Browserprüfung
mit Beispieldaten bestätigt Notiz- und Codesuche, kombinierte Filter, Zurücksetzen
und das Öffnen und Schließen der Details bei 390 × 844 Pixeln ohne horizontales
Überlaufen. Alle 13 Prüfungen im isolierten HA-Core-Lauf sind bestanden; alle acht Web-Dateien
sind erreichbar. Einzelheiten stehen im [Teststand](../TESTING.de.md).

Im Marketplace Vorabversionen einschließen, **0.1.0b7** auswählen und installieren.
Home Assistant anschließend neu starten und das Panel vollständig neu laden.
[Installation](../INSTALLATION.de.md).

Die Version ist weiterhin eine Beta. Die offene praktische Abnahme steht im
[Teststand](../TESTING.de.md). Das Inventarformat benötigt keine Migration.
