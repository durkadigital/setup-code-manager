# Setup Code Manager 0.1.0b13

- Der Editor zeigt Scanfortschritt, erkannte Codes und Fehler direkt über **Speichern**. Die Meldung bleibt beim Scrollen sichtbar.
- Der Fokus bleibt beim Codebereich. Nach einem erfolgreichen Scan zeigt der Editor **Code erkannt**. **Gerät gespeichert** erscheint erst nach dem Speichern.
- Beim Ändern oder Entfernen des erkannten Codes verschwindet die Bestätigung.

Mit gültigen und ungültigen Testbildern bei iPhone-Breite und am Desktop geprüft. Der Praxistest in der iPhone-App steht noch aus.

Für das Update im Marketplace Vorabversionen einschließen, **0.1.0b13** auswählen und Home Assistant anschließend neu starten. [Installation](../INSTALLATION.de.md)
