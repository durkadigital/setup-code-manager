# Setup Code Manager 0.1.0

Erste reguläre Version von Setup Code Manager. Sie enthält den Funktionsumfang von 0.1.0b14 und benötigt Home Assistant 2026.11.0 oder neuer.

- Einrichtungscodes für Matter, HomeKit und Z-Wave erfassen und verwalten.
- Geräte nach erneuter Kopplung mit ihrem bestehenden Inventareintrag verknüpfen und gespeicherte Codes und Notizen behalten.
- Geräte filtern, Ansichten speichern und Codes als JSON, CSV oder PDF exportieren.

Die Version kann mit den normalen Marketplace-Einstellungen installiert werden. Nach einem Update Home Assistant neu starten. [Installation](https://github.com/durkadigital/setup-code-manager/blob/0.1.0/docs/INSTALLATION.de.md)
